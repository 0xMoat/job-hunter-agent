# Plan Quality

评估 Plan-and-Execute Agent 的 Planner 节点生成的**初始 plan** 的质量。
仅关注首次产出的步骤列表，不评估后续执行结果。

## 评分维度

- 步骤是否覆盖了用户目标所需的所有关键动作
- 步骤是否原子化（一步一个明确动作）
- 是否避免了无效步骤（重复、冗余、与可用工具能力不符）
- 步骤顺序是否合理（如：先研究公司 → 再写求职信 → 最后更新看板）

## 打分（连续值 0-1）

- **1.0**：完全覆盖目标，所有步骤原子化，顺序合理，无冗余
- **0.8**：覆盖充分，个别步骤粒度略粗或可合并
- **0.6**：基本覆盖，有 1–2 处明显冗余或顺序问题
- **0.4**：遗漏关键动作或顺序混乱
- **0.2**：几乎不可执行，与目标脱节
- **0.0**：空 plan 或完全错误
